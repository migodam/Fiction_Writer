## Changes
- Added explicit DeepSeek V4 Flash and Pro cache-miss pricing, pricing version/source metadata, and exact-safe longest model matching. Legacy pricing entries remain; there is no generic `deepseek-v4` match.
- Added fail-closed `BudgetPolicy` / `BudgetLedger`, remaining-budget snapshots, unknown-pricing and missing-usage handling, pre-call cancellation, and post-call crossing cancellation.
- Made the gated ten-chapter runner default to `deepseek-v4-flash`; only Flash/Pro are accepted. It passes a USD/token/call policy (`--max-cost-usd` defaults to `3.0`) and explicit zero rerun caps.
- Added hard required-artifact checks and recursive generated-artifact secret scanning. Runner fails 402/budget, timeout, and authentication states.

## Lead Integration Hook
The pipeline must enforce the new API inside `sidecar/workflows/w1_import.py` before every `llm.ainvoke(...)` (currently legacy calls include lines 2541, 2612, and 2652; supervisor call is `sidecar/supervisor/tools.py:877`). At run setup, parse `config["budget_policy"]` and call `configure_budget(session_id, BudgetPolicy(**policy), model=model)`. Immediately before each call, call `budget_allows_call(session_id, estimated_input_tokens=..., estimated_output_tokens=..., model=model)` and exit/cancel when false. Immediately after every response, call `record_call_usage(session_id, input_tokens, output_tokens, model=model)` even if usage is missing. This is the required hook that ensures a crossing stops the next provider call; E0 intentionally did not edit forbidden pipeline files.
